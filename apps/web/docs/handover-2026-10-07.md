- **Coolify**: builds `apps/web/Dockerfile`. `npm ci` runs under npm 10, so after any dependency change regenerate the lockfile with `npx npm@10.8.2 install --package-lock-only --ignore-scripts` and check `npx npm@10.8.2 ci --dry-run --ignore-scripts`. The npm 11 used locally drops an optional `@swc/helpers` entry and breaks the deploy.
